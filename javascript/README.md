## 🚀 Sobre o curso

O curso aborda desenvolvimento web moderno do zero ao avançado, passando por frontend, backend, bancos de dados, APIs e frameworks modernos do ecossistema JavaScript.

### Tecnologias estudadas

- HTML5
- CSS3
- JavaScript
- TypeScript
- Node.js
- React
- Angular
- Vue.js
- Express
- MySQL
- MongoDB
